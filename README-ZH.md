
# Apple Music 歌单转换器

一个简洁优雅的工具，用于将 Apple Music 导出的歌单或整个资料库转换为其他音乐播放器能识别的格式。

## ✨ 特性

- 🎵 **纯本地处理** - 你的数据永远不会离开浏览器
- 🔄 **多种输出格式** - 支持各种音乐播放器
- 🌙 **暗色模式支持** - 自动适配系统主题
- 🎯 **智能处理** - 去重和空格清理
- 📋 **一键复制/下载** - 使用简单方便

## 📦 输出格式

| 格式 | 说明 | 适用场景 |
|------|------|----------|
| 歌手 - 歌名 | 标准格式 | 大多数播放器 |
| 歌名 - 歌手 | 倒序格式 | 部分播放器 |
| 仅歌名 | 简单列表 | 快速导入 |
| 仅歌手 | 歌手列表 | 筛选收藏 |
| CSV | 表格格式 | Excel 编辑 |
| M3U | 播放列表 | 专业播放器 |

## 🚀 快速开始

1. **从 Apple Music 导出**（电脑端）
   - 选中你的歌单
   - 前往菜单栏->文件->资料库->导出播放列表或导出资料库
   - 打开导出后的文档或上传

2. **使用本工具转换**
   - 粘贴到输入框或上传导出文件
   - 选择输出格式
   - 点击"转换歌单"
   - 复制或下载结果

3. **导入到你的音乐播放器**
   - 大多数播放器支持拖拽或从文本文件导入
   - 支持网易云音乐、QQ音乐等播放器
